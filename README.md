# Annamitra

AI-assisted Indian food nutrition estimates from a plate photo. Fourth-year project: React PWA frontend first, then Node/Express + MongoDB.

Current milestone: camera or image upload → mock Indian food detection (dal, roti, sabzi) → estimated nutrition → daily dashboard.

```bash
cd frontend
npm install
npm run dev
```

Open the local URL on a phone on the same network to try the camera. Nutrition values are estimates from detected foods, typical portions, and a database — not lab measurements.
